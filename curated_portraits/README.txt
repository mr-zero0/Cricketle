========================================================================
CRICKETLE - CURATED PORTRAIT PHOTOS DIRECTORY
========================================================================

HOW TO ADD PHOTOS:
1. Open any player folder inside `01_active_players` or `02_all_time_legends`.
2. Paste 3 to 5 distinct, natural portrait photos (facial headshots) of that cricketer.
3. You can name the files whatever you want (e.g., 1.jpg, 2.jpg, photo.png, etc.).
4. Any standard image format is supported (.jpg, .jpeg, .png, .webp).

SECURITY & ANTI-BACKTRACKING:
- This folder is located OUTSIDE the `public/` web server directory.
- It is completely inaccessible to browser clients and cannot be backtracked or inspected from the UI/network tab.
- When imported into the game, image filenames are automatically anonymized with cryptographic hashes (e.g. p_a7f92b.jpg) so the player's name is never revealed in the browser!

ROSTER SUMMARY:
- 01_active_players (30 players: IDs 01 to 30)
- 02_all_time_legends (25 players: IDs 31 to 55)
