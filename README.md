# 🏏 Cricketle

A Wordle-inspired daily cricket guessing game. Test your cricket knowledge by guessing the secret cricketer! Every guess provides contextual clues and indicators to help you narrow down the player.

## 🎯 How to Play

1. **Enter a Guess**: Search and pick any international or franchise cricketer from the dataset.
2. **Analyze Feedback**: Compare attributes between your guess and the mystery cricketer:
   - **Nationality / Country**
   - **Playing Role** (Batter, Bowler, All-Rounder, Wicketkeeper)
   - **Batting / Bowling Style**
   - **Age / Era / Active Years** (indicated by directional arrows: higher/lower)
   - **Matches / Stats**
3. **Difficulty Modes**:
   - **Easy Mode**: Classic clues with broader indicators.
   - **Hard Mode**: Tightened clues for cricket aficionados.
4. **Solve the Daily Puzzles**: 5 daily puzzles refreshed every 24 hours. Track your streak and share results with friends!

## ✨ Features

- **Dynamic Animated Background**: Interactive HTML5 canvas with cricket ball and pitch visual effects.
- **Rich Player Database**: Comprehensive list of modern and legendary cricketers.
- **Streak & Stat Tracking**: Local persistence of puzzle completions, guess counts, and streaks.
- **Responsive Design**: Polished mobile and desktop experience with modern typography and sleek dark mode aesthetics.
- **Zero Dependencies**: Pure Vanilla HTML, CSS, and JavaScript.

## 🚀 Running Locally

No build step required! Simply clone and open:

```bash
git clone https://github.com/mr-zero0/Cricketle.git
cd Cricketle
```

Open `index.html` directly in your browser or run a lightweight local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx
npx serve .
```

Then visit `http://localhost:8000` in your web browser.
